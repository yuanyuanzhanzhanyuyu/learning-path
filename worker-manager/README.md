# 职工管理系统

C++ 面向对象练习：基于继承与多态的控制台职工管理程序。

## 功能
- 添加职工（普通员工 / 经理 / 老板三类岗位）
- 展示职工信息（多态调用，不同岗位输出不同内容）
- 数据保存到文件，启动时自动恢复

## 技术点
- 抽象基类 + 纯虚函数：worker 定义统一接口
- 多态：employee / manager / boss 继承 worker，用基类指针数组 worker** 统一管理不同岗位对象
- 文件读写：数据持久化到 employee_file.txt，启动时判断空文件并恢复
- RAII：析构函数统一释放堆上对象

## 编译运行
g++ *.cpp -o worker-manager
