# 网费管理系统（链表实现）

大一下学期 C/C++ 课程设计：模拟校园机房计费管理的控制台程序。

## 功能
- 上网卡管理：开卡、注销（逻辑删除）、按卡号精确 / 模糊查询
- 上机 / 下机：按 time_t 时间戳计时计费，自动生成消费账单
- 充值 / 退费：记录每笔资金流水
- 查询统计：余额、累计消费、使用次数

## 技术点
- 手写链表管理卡与账单数据，new / delete 自行管理内存
- 逻辑删除：记录带删除标志位，查询时过滤而非直接摘链
- 双格式持久化：卡数据同时保存文本与二进制格式，启动读入、操作后写回
- 多文件结构：data.h 统一定义数据结构，card / bill / menu 模块声明与实现分离

## 文件说明
- main.cpp：主菜单与流程分发
- card.h/.cpp：上网卡增删查、文件读写
- bill.h/.cpp：上下机计费、充值退费、统计
- menu.h/.cpp：菜单显示
- data.h：CARD / BILL / MONEY 结构体与链表定义

## 编译运行
Visual Studio 用户直接双击 Project1.vcxproj 打开工程即可编译运行；或用 g++：

g++ main.cpp card.cpp bill.cpp menu.cpp -o internet-fee-manager

首次运行前请确保目录下存在 data 文件夹（仓库中已包含示例数据文件）。
